FortiGate Config Generator

Utilitas lokal untuk membuat konfigurasi IP/FQDN dan mengonversi command menjadi CSV.

2) Nama Group

Bantuan Singkat

  • IP tanpa CIDR otomatis menjadi /32 untuk IPv4 atau /128 untuk IPv6.
  • Duplikat dihapus dengan urutan tetap.
  • Domain dibuat sebagai FQDN wildcard: set fqdn *.example.com.
  • Output dapat disalin atau diunduh.

Output – Gabungan




1) IP FortiGate
Setiap IP akan mendapatkan seluruh command di bawah, dengan sequence dimulai dari 1.
2) Commands FortiGate
Spasi pada nama setelah edit otomatis diubah menjadi backslash-space. Contoh: edit Link\ Internet.


Format Output
CSV menggunakan tiga kolom berikut:
ip,sequence,command
192.168.20.254,1,config firewall addrgrp
192.168.20.254,2,edit Link\ Internet
192.168.20.254,3,append member internet.id
192.168.20.254,4,next
192.168.20.254,5,end
  • Header CSV otomatis dibuat.
  • Sequence diulang dari 1 untuk setiap IP.
  • Command yang mengandung koma akan di-quote sesuai format CSV.
  • Hasil hanya berupa teks; tidak ada koneksi langsung ke FortiGate.
